# Linux Lab

My hands-on Linux administration learning repository.

## Structure

- `weeks/week-01/` — Week 1 exercises and deliverables
- `notes/` — Learning notes and troubleshooting records
- `scripts/` — Shell scripts
- `configs/` — Configuration examples

## Workflow

- Type commands manually and inspect their output.
- Record problems using symptom, cause, and fix.
- Test changes before treating them as complete.
- Never commit secrets, passwords, or private keys.
